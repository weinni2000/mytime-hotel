Upload the site's map image on the ``campsite.map`` record, then recalibrate
each ``camping.map.zone``'s ``points`` field to match its pixel dimensions -
the demo zones ship with placeholder rectangles and need to be redrawn by eye
against the real image (open a ``campsite.map`` record's "Map Preview" or
"Testing" tab in the backend, compare the overlay to the photo, and adjust the
polygon coordinates accordingly).

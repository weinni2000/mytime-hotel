Mail to Booking

Turn booking-platform emails and direct guest inquiries into ready-to-confirm sale orders automatically, using DeepSeek to read each incoming message for you.

Odoo 19.0 Mail & Rental Powered by DeepSeek

What it does

Enable it on an incoming mail server and every email that arrives is checked for a camping or vehicle-rental booking - no manual copy-pasting from platform notifications or guest emails into a sale order.

1

Reads the whole email, PDF included

The message body is cleaned of HTML/CSS noise and, if a PDF is attached (e.g. a booking-platform confirmation), its text is extracted with pdfminer and appended before analysis.

2

DeepSeek extracts the booking details

Guest name, phone, email, check-in/check-out dates, nights, adults, vehicles, price, platform and a product hint are pulled out of the text in one API call.

3

Draft sale orders, never silently confirmed blind

A matching sale.order is created and confirmed automatically, with rental dates set when check-in/check-out were found - the full original email stays attached in its chatter.

4

Product matching that learns

A hint is matched against saved mappings first, then against a channel's allowed products via DeepSeek, or by a unique product-name search - each successful match is saved for next time.

5

Subject blocklist skips the noise

Recurring non-booking subjects (newsletters, internal alerts) can be blocklisted per sales channel so they're marked "Not a Booking" without ever calling the API.

6

Guest matching without mix-ups

Guests are matched by email, phone or name - and a shared forwarding mailbox address can be excluded so it never gets mistaken for a returning guest's own address.

From inbox to booking

Every step is tracked on a mail.to.booking record, so nothing that couldn't be handled automatically disappears silently - it waits with a clear reason and a one-click fix.

Setting it up

From a blank mail server to automatic bookings, in a few steps.

  1. Add a DeepSeek API key to the company. Settings > Users & Companies > Companies, tab "Booking Sync", enter the key used for extraction.
  2. Enable detection on the incoming mail server. Technical > Email > Incoming Mail Servers, open the booking mailbox and tick "Buchungen per DeepSeek erkennen".
  3. Restrict which products can be matched (optional). Set "Zulässige Produkte" on the mail server to the room/pitch offers this mailbox may book, so DeepSeek only ever chooses among them.
  4. Review results under Sales > Bookings > Mail-Buchungen. Records that need a decision show as "Product Missing" or stay in draft - resolve them with the "Choose Product" or "Not a Booking" wizard.
  5. Exclude shared forwarding addresses. If bookings arrive via a shared inbox (e.g. bookings@yourdomain.eu), add that address under Sales > Bookings > Excluded Emails so it's never used to match an existing guest.
The DeepSeek API key itself is not bundled with this module. A companion module can set it automatically for a given installation; otherwise enter it manually on the company record before enabling detection on any mail server.
